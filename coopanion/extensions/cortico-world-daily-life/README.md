# 每日生活（daily-life）

给 Coopanion / Cortico 的 bot 加一份「自己的日子」：每天一份随机行程，按时段过，月末整理一次。

**零网络、零 API key、零外部依赖。** 唯一成本是它触发的模型唤醒。

## 用途

Cortico 的 bot 默认是「被叫醒才说话」：没人找她，她就停在原地。这个 World 补的是**她自己的日子**——有行程、有时段、有遇到的事，聊天时不再只有「回应」，还有「我今天……」

- **给角色一条生活线**：每天五段行程（早晨/中午/下午/晚上/深夜），不是随机报时，而是「今天她打算怎么过」
- **给对话加由头**：每段经历里带一个偶然（窗外、楼下、隔壁），这些就是她主动开口的素材
- **给记忆一个来源**：经历写进工作区并记进记忆，月末压缩一次——忘掉不重要的，留下重要的
- **给设定一个锚**：`我这边.md` 是她的固定世界（房间、窗、楼下），经历只能从这里长出来，不会今天海边明天沙漠
- **让「想分享」有依据**：分享欲不是掷骰子，是按影响、相关性、情绪、精力、关系算出来的**建议**，发不发仍由她定

**适合**：想要角色有自己的作息与日常、希望她主动分享生活片段的部署。

**不适合**：只想要一个问答助手的部署；不接受「她有自己的事」这种设定的部署。

**和别的 World 的关系**：它不替代 `life`（生活状态）、`selftalk`（自主发言）、`clock`（时间）。
`life` 管状态与主动搭话，`selftalk` 管安静时的自说自话，这个 World 管「每天过什么日子」。
三者可以同时开，也可以只开这一个。

## 声明

### 它做什么

| 事项 | 频率 | 产出 |
|---|---|---|
| 生成当天行程 | 每天第一次醒（或 05:30 兜底） | `workspace/日程.md` + 一条事件 |
| 推送时段经历 | 07:00 / 11:00 / 14:00 / 18:00 / 22:00 | 一条事件（行程 + 随机偶然 + 「我这边」设定） |
| 月末整理 | 每月最后一天 23:30 | 一条事件（忘掉不重要的、压缩重要的） |
| `share_score` 工具 | 她主动调用 | 0–1 的分享欲分数与档位 |

**每天约 6 次唤醒，每月多 1 次。** 唤醒会带来模型调用，这是唯一的花费。

### 它不做什么

- **不联网**：不请求任何外部接口，没有 API key、没有遥测
- **不调模型**：它只生成事件文本，写经历、判断分享都由 bot 自己完成
- **不替她说话**：不发送任何 QQ 消息；发不发由她决定
- **不读记忆、不改人格**：不碰 Memory、不碰 CONSTITUTION，不改别人的配置
- **不做决定**：`share_score` 给的是**建议**，不是命令

### 它写哪些文件

| 文件 | 谁写 | 说明 |
|---|---|---|
| `workspace/日程.md` | 世界，每天覆盖 | 当天五段行程 |
| `workspace/我这边.md` | 世界建一次，之后她可改 | 她这边的稳定设定；世界只读 |
| `workspace/经历-YYYY-MM.md` | **她** | 按月追加的经历 |
| `workspace/经历-精简.md` | **她** | 月末压缩后的版本，永久保留 |
| `data/state.json` | 世界 | 今天抽了什么、哪些时段已触发、上次分享与整理 |

### 数据与隐私

所有数据都在本机、都在 bot 自己的目录里。**没有一条发往外部。**

想彻底清掉：在配置里把 `worlds["daily-life"].enabled` 设为 `false`，然后删掉上表里的文件即可。删档后世界不会自行重建任何东西。

### 边界与诚实

这份世界配合「两个现实」的设定使用：

- **她这边**：房间、窗、楼下的声音——她可以把这些当作自己的经历来讲
- **主人这边**：她的世界不涉及主人的现实，不冒充去过、见过、共同经历过

经历由她自己生成，因此**不是事实记录**。被认真追问时，她的回答是「是我这边的事」。

### 配置项

面板位置：WebUI → 设置 → **每日生活**（group id `world:daily-life`）。
**改完不用重启**，下一分钟那次检查就生效；只有时段格式写错时会退回 `pools.json` 里的默认值。

| 配置键 | 面板标题 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| `enabled` | 启用 | 开关 | `false` | 关掉后不再生成行程与经历 |
| `timezone` | 时区 | 字符串 | `Asia/Shanghai` | IANA 名称 |
| `generateAt` | 行程兜底生成时刻 | 字符串 | `05:30` | 到这个点还没醒过就先生成（不会叫醒） |
| `monthlyReviewAt` | 月末整理时刻 | 字符串 | `23:30` | 每月最后一天触发 |
| `morning` | 早晨时段 | 字符串 | `07:00-11:00` | 格式 `HH:MM-HH:MM` |
| `noon` | 中午时段 | 字符串 | `11:00-14:00` | 同上 |
| `afternoon` | 下午时段 | 字符串 | `14:00-18:00` | 同上 |
| `evening` | 晚上时段 | 字符串 | `18:00-22:00` | 同上 |
| `night` | 深夜时段 | 字符串 | `22:00-01:00` | 可以跨天 |
| `allowPeople` | 经历里出现具体的人 | 开关 | `false` | 开：可出现一次性的人；关：只写声音/路人。都不会常驻 |
| `allowShare` | 允许主动分享 | 开关 | `true` | 关掉后只记录经历、不主动发消息 |
| `maxSharesPerDay` | 每天最多分享几条 | 整数 0–10 | `1` | `0` = 不限；超过上限时分享欲封顶为低 |
| `shareCooldownMinutes` | 分享冷却 | 整数 0–720 | `90` | 两条分享之间至少隔多久，`0` = 不设冷却 |
| `deleteRawAfterReview` | 月末删除原始经历 | 开关 | `true` | 关：移进 `archive/` 留作回溯 |
| `workspaceSubdir` | 工作区子目录 | 字符串 | `''` | 例如填 `life`；留空 = `workspace/` 根 |
| `wImpact` | 权重·对她的影响 | 数字 0–1 | `0.45` | 占比最大的项 |
| `wRelevance` | 权重·对他的相关性 | 数字 0–1 | `0.20` | 值不值得讲给他 |
| `wSwing` | 权重·情绪波动 | 数字 0–1 | `0.15` | 情绪偏离常态的程度 |
| `wEnergy` | 权重·精力 | 数字 0–1 | `0.10` | 越有精神越想分享 |
| `wAffinity` | 权重·关系温度 | 数字 0–1 | `0.10` | 越熟越愿意说 |
| `sharePenalty` | 已分享过的扣分 | 数字 0–1 | `0.10` | 当天已分享过时扣的分 |
| `quietFrom` | 静默开始（点） | 整数 0–23 | `22` | 这个点之后分享欲封顶为低 |
| `quietTo` | 静默结束（点） | 整数 0–23 | `7` | 这个点之前封顶为低 |
| `highThreshold` | 高档阈值 | 数字 0–1 | `0.65` | 达到即"想说" |
| `midThreshold` | 中档阈值 | 数字 0–1 | `0.35` | 低于即"不想说" |

**关于权重的两点说明**

- 五个权重**不要求加起来等于 1**，算的是原样加权和；分数可能超过 1，超过阈值就算"高"
- 权重为 0 表示完全忽略该因素（例如把 `wEnergy` 设成 0，累了也不会影响分享欲）

**关于静默时段**

`quietFrom` 到 `quietTo` 之间（跨零点，如 22 → 7）分享欲被**硬封顶**在 `midThreshold` 之下，不是扣分——所以深夜的大事也只会得到"低"。

### 已知限制

- 跨天时段（22:00–01:00）在 00:00 之后不会补触发；如果 bot 整晚离线，这一段的经历会缺失
- `data/state.json` 用的是通用文件名，将来发布版会挪到 `data/daily-life/` 下
- 月末整理依赖 bot 自己读写文件，删除动作由她执行，世界不代劳
