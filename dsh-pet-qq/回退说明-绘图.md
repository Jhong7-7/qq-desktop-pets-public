## 它做什么

溪颜在回复里写一行标记，桥就去画一张图、发到 QQ：

```
[画:一只趴在窗台睡觉的橘猫]
[画:一只橘猫|水墨|精细|竖图]     ← 画风 | 精细度 | 比例
[画:一只橘猫|水墨|竖图|*窗边放着他落下的外套，午后斜光]  ← * 是她自己加的构思
```

- 标记格式：`[画:…]` / `[绘图:…]` / `[给我画:…]`，中英文冒号、全角半角括号都认。
- 29 种画风（日漫/水墨/赛博朋克/Q版/油画…）+ 3 档精细度（草图/标准/精细）+ 比例（方图/竖图/横图/16:9）。
- **`* / + / 我的想法: / 我加的:` 开头的最后一段 = 她自己添的细节**（光线、角度、情绪、小物件、氛围）。桥会把这段独立拼进送模型的 prompt，排在画风锚点前面；哥哥给的主体不会被它顶掉。
- 一轮问答变两轮：她写标记 → 桥生图（约 40 秒）→ 把"你画好了"交回去，她配一句话 → 图作为独立图片消息发出。
- 先回一句"好嘞，我画一下，稍等哈"，避免 40 秒像卡住。
- 失败一律降级：剥掉标记、让她说实话，绝不把 `[画:xxx]` 字面发到 QQ。

## 重启桥的方式

explorer 中转不稳定；用计划任务拉起（父进程是系统服务，脱离工具会话、不会被回收）：

```powershell
$nodeExe='C:\Users\86189\.workbuddy\binaries\node\versions\22.22.2-6\node.exe'
$bridge='D:\dsh workplace\tools\dsh-pet-qq\bridge.mjs'
$a=New-ScheduledTaskAction -Execute $nodeExe -Argument ('"{0}"' -f $bridge) -WorkingDirectory 'D:\dsh workplace\tools\dsh-pet-qq'
$t=New-ScheduledTaskTrigger -Once -At (Get-Date).AddSeconds(-10)
$p=New-ScheduledTaskPrincipal -UserId "$env:USERDOMAIN\$env:USERNAME" -LogonType Interactive -RunLevel Limited
Register-ScheduledTask -TaskName XiyanBridgeRelaunch -Action $a -Trigger $t -Principal $p -Force | Out-Null
Start-ScheduledTask -TaskName XiyanBridgeRelaunch
Start-Sleep 3; Unregister-ScheduledTask -TaskName XiyanBridgeRelaunch -Confirm:$false
```

若重启后桌面弹出黑色命令行窗口，跑一次 `hide-console.ps1` 隐藏（不动桥进程）。
